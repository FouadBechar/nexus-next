# Roadmap

This document outlines the planned evolution of Nexus Next.

The project is currently in beta with a stable production deployment and an actively evolving architecture. Priorities may change as the project grows and new ideas emerge.

## Current Beta

The following features are already available:

* Multi-model chat through OpenRouter
* Google AI Studio support
* Streaming responses
* Clerk authentication
* Supabase persistence for signed-in chats and messages
* Local persistence fallback for signed-out users
* Search across loaded chat titles and messages
* Settings for model, temperature, and system prompt
* Markdown and JSON chat export
* Image, PDF, text, and Markdown attachments
* Persisted extraction metadata for readable text-based uploads
* Mobile-friendly chat layout
* Vercel deployment
* Linux and Windows development support

## Near-Term Goals

Planned improvements for upcoming releases:

* PDF export
* Theme controls (Light / Dark / System)
* OCR or improved fallback handling for scanned PDFs
* Supabase-backed full-text search for larger chat histories
* Better model metadata and capability indicators
* Improved attachment previews
* Better mobile experience and responsiveness
* Additional AI provider integrations

## Long-Term Vision

Larger initiatives planned for future versions:

* Retrieval-Augmented Generation (RAG) over uploaded files
* Agent workflows
* Shared and public chat links
* Knowledge base support
* Usage tracking and cost visibility
* Advanced search and filtering
* Public landing page
* Workspace-style organization for chats and files

## Guiding Principles

As Nexus Next evolves, the project aims to remain:

* Fast and lightweight
* Developer-friendly
* Provider-agnostic
* Open-source friendly
* Mobile responsive
* Easy to extend and maintain

The goal is to build a modern AI workspace that can grow from a simple chat application into a flexible platform for AI-powered workflows.
